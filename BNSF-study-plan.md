# BNSF Railway Study Plan
A 3 day plan of coding problems focused on medium-difficulty, arrays/data-structures, and the expectation that I must explain my critical thinking and trade-offs.

## DAY 1 — Core Arrays & Hashing (FOUNDATION)
Goal: Become very comfortable explaining why hash maps, two pointers, and prefix sums work.

### Problems
* [ ] **Two Sum**  
LC-1  
Why: Hash map reasoning, trade-offs vs brute force
* [ ] **Contains Duplicate**  
LC-217  
Why: Set vs sorting
* [ ] **Product of Array Except Self**  
LC-238  
Why: Prefix/suffix logic
* [ ] **Maximum Subarray (Kadane’s Algorithm)**  
LC-53  
Why: Dynamic thinking
* [ ] **Subarray Sum Equals K**  
LC-560  
Why: Prefix sum + hash map

### Outcome
You should be able to clearly explain:
* Hash maps
* Prefix sums
* Why brute force fails
* Space/time trade-offs
